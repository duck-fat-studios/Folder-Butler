# FolderButler Public Releases

This repository is the public download home for FolderButler builds.
The application source code is not published here. This repo exists so the app
has a stable place to publish signed macOS releases, update metadata,
third-party notices, and checksums.

## Downloads

Use the **Releases** page for installers and zipped app builds:

https://github.com/duck-fat-studios/Folder-Butler/releases

The release assets are the files to use. GitHub may also show automatic
"Source code" archives for the public artifact repository tag; those archives
are generated by GitHub and do not contain the private FolderButler source.

FolderButler also reads `appcast.xml` from this repository for automatic
updates. That feed is meant for the app, not for people to hand-edit.

## What FolderButler Is

FolderButler is a desktop utility for turning the small, repetitive file chores
on your Mac into simple rules. It can watch folders, run scheduled cleanup,
react to app activity, move or copy files, keep backups, play sounds, run
commands, and handle the kinds of “I do this every week” tasks that are easy to
forget and annoying to repeat.

The goal is not to be a developer-only automation kit. The goal is a calm,
practical app that normal people can trust. Rules should be understandable,
permissions should be explained before they surprise you, and anything that
needs elevated access should be optional and clearly marked.

FolderButler is built around a few plain ideas:

- Automation should feel reversible and inspectable.
- The app should work without admin approval for everyday use.
- Advanced features can exist, but they should not make the basic experience
  harder.
- Local-first behavior matters. Your rules are yours.
